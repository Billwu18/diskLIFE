# Code of conduct · 行为准则

Short version: **be decent.** This project is about making something small and pleasant; people of any
skill level, language, and background should be able to ask a question here without being made to feel
stupid.

短版：**好好说话。** 这个项目做的是小而舒服的东西，任何水平、语言、背景的人都应该能在这里提问而
不必担心被嘲笑。

## Expected · 期望行为

- Assume the other person is acting in good faith; ask before accusing.
- Critique code and decisions, not people. "This drops the error code" beats "you clearly don't test".
- Technical questions in any language are welcome. The maintainer answers in Chinese or English.
- When you are wrong, say so and move on; when someone else is wrong, correct them kindly.
- Respect the scope: "won't merge" decisions (see [CONTRIBUTING.md](CONTRIBUTING.md)) are about the
  project, not about you.

## Not acceptable · 不可接受

- Harassment, insults, slurs, or sexual attention of any kind.
- Publishing others' private information (addresses, real names, credentials, chat logs) without consent.
- Doxxing, brigading, or dragging in unrelated drama.
- Sustained disruption of issues/PRs, or bad-faith demands on unpaid maintainers.
- Using this project to distribute someone else's copyrighted character or private data.

## Enforcement · 执行

Report problems to the maintainers privately (open an issue titled `[conduct] contact request` with no
details, or use the security advisory channel in [SECURITY.md](SECURITY.md)). Reports are read by the
maintainer only. Consequences, up to a permanent ban, are at the maintainer's discretion and will be
explained to the person concerned.

问题请私下报告维护者（见 `SECURITY.md` 的渠道）。处理结果（从提醒到永久封禁）由维护者决定，并会向当事人说明。
