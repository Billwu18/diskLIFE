DiscPersona Studio

把一个人设，做成一张能插进光驱的光盘

dsh — 插件包 — AI 起草 —

她是谁

名字会印在光盘标签、浏览器标题和「出生」那句话说出口的时候。

支持 Character Card V2/V3 的 .png（内嵌 chara 数据）或 .json

她活在哪个世界

这一段会写进 system prompt 的「你是谁」。写得具体，她就稳；写得空，她会漂。

她怎么说话

人设的效果，八成落在这一页。给她具体的口癖、称呼和句子长度。

她的性格与底线

性格写「行为倾向」，底线写「绝不」。底线会原样进入 system prompt 的最后一段。

出生、醒来、休眠

这些话会出现在启动器与首页；也是「仪式感」的全部来源。

她一开始就记得的事

这些文件会在第一次启动时放进她的工作区。不需要很长，两页就够。

?

会裁成 512×512 的 PNG，同时生成头像与光盘图标。留空则用主题色生成一个占位图标。

出厂

先选插件包，再导出人设包、打成光盘目录，最后（可选）生成 ISO 并刻录。

口令不会写进光盘或房间；丢失后无法解密。房间里的解密副本仍受系统权限/全盘加密保护。

1

导出人设包

persona\<slug>\

2

打包成光盘目录

examples\<slug>\

3

生成 ISO

build\<slug>.iso

4

刻到光盘

需要一张空白 CD-R / DVD-R
